# Logo Guess App Gameplay Checklist

Use this checklist when changing quiz content or scoring.

- Confirm each displayed logo maps to the intended answer.
- Handle answers consistently with the documented case and whitespace rules.
- Award points only once for a correctly completed question.
- Provide useful feedback for correct, incorrect, and skipped answers.
- Verify question progression and end-of-quiz behavior.
- Check that images have suitable alternatives and remain readable on small screens.
