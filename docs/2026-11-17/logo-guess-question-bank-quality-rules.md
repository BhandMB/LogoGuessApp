# Logo Guess Question Bank Quality Rules

## Content rules
Each question should have one unambiguous expected answer, a suitable difficulty label, and a reviewed asset reference.

## Data checks
Detect duplicate questions, duplicate normalized answers, missing image references, empty hints, and inconsistent category metadata.

## Player experience
Avoid answer variants that unfairly penalize harmless differences in spacing or capitalization. Review hints so they help without revealing the answer immediately.

## Release gate
Sample questions across categories and difficulty levels. Record content reviewer, issue, correction, and review date.
