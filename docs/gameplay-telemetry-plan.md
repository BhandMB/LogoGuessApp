# Gameplay Telemetry Plan

Track only data needed to improve the game experience:

- Round started
- Guess submitted
- Guess result: correct or incorrect
- Hint used
- Round completed

## Quality rules
- Do not collect personal or device-identifying information.
- Keep event names stable and documented.
- Record timestamps in a consistent format.
- Verify that offline play continues to work when telemetry is unavailable.
