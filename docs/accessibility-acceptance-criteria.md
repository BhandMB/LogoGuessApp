# Accessibility Acceptance Criteria

Before release, verify that gameplay remains usable with common accessibility settings.

- All interactive controls are reachable with keyboard or switch navigation.
- Focus order follows the visual order and remains visible.
- Images and icons have meaningful labels or are marked decorative.
- Text and controls remain readable when font size is increased.
- Feedback for correct, incorrect, and unavailable actions is not conveyed by color alone.
- Touch targets remain usable on smaller screens.

Record the device, operating-system version, accessibility settings, and observed result for each check.
