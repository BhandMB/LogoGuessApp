# LogoGuessApp Accessibility Review

Review the game from the perspective of keyboard, screen-reader, and small-screen users.

- [ ] Every text input has a programmatic or visible label.
- [ ] Interactive controls expose clear names and purposes.
- [ ] Keyboard focus is visible and follows a logical order.
- [ ] Correct/incorrect feedback is available as text, not color alone.
- [ ] Score and progress updates are announced or otherwise easy to discover.
- [ ] Logo images have appropriate alternative text where meaningful.
- [ ] Text remains readable at common zoom levels.
- [ ] Buttons and inputs are usable on narrow screens.
- [ ] Restart and next-question actions are clearly distinguished.
- [ ] A full game session can be completed without unexpected focus loss.
