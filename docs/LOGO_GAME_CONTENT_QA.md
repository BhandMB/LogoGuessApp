# LogoGuessApp Content QA Checklist

Use this checklist when adding or updating logo questions and answer data.

- [ ] Each question has a stable identifier if the data model supports one.
- [ ] Each question references an available image asset.
- [ ] Accepted answers and aliases are spelled consistently.
- [ ] Duplicate questions are reviewed for unintended repetition.
- [ ] Difficulty and category labels, if present, follow a consistent convention.
- [ ] Missing assets or malformed question data do not crash the game.
- [ ] Answer matching behavior is documented, including case and whitespace handling.
- [ ] Assets are used in accordance with their applicable licenses and project requirements.
- [ ] A representative game session is tested after content updates.
