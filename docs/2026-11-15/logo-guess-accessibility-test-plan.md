# Logo Guess Accessibility Test Plan

## Interaction checks
- Complete a round using keyboard controls alone.
- Ensure answer choices have clear accessible names and visible focus.
- Announce correct, incorrect, and completion states to assistive technology.
- Do not communicate correctness using color alone.

## Visual checks
Verify text contrast, scalable text, and usable layout at narrow widths and high zoom.

A player should understand the prompt, submit an answer, and receive feedback without relying solely on pointer input, color, or audio.
