# Question bank difficulty and answer quality review

## Review dimensions
Assess each question for unambiguous intended answer, appropriate difficulty, spelling, duplicate content, visual clarity, and suitability for the target audience.

## Answer rules
Define accepted aliases, spacing/case normalization, punctuation handling, and whether partial answers are allowed. Avoid overly broad aliases that make unrelated brands correct. Keep answer validation deterministic and separate from display hints.

## Difficulty balance
Tag questions using a documented scale and sample each level for fairness. Review whether image resolution, cropping, or visual similarity creates accidental difficulty unrelated to knowledge.

## Release checks
Run duplicate detection, manual answer review, device-size checks, and a small playtest. Track reviewer, date, disposition, and reason for each corrected or removed question.
