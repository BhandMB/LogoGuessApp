# Logo Guess App Content Release Review

## Purpose
Establish a repeatable review before publishing a new logo-question pack.

## Content quality
- Confirm each image corresponds to the intended answer.
- Check spelling, accepted aliases, and answer normalization.
- Avoid ambiguous crops where multiple brands could reasonably fit.
- Review difficulty progression and duplicate questions.
- Confirm hints reveal useful information without giving away the answer immediately.

## Rights and attribution
Track the source and permitted use for every asset. Prefer original, licensed, or otherwise authorized material. A publicly viewable image is not automatically free to reuse. Keep attribution requirements with the asset metadata.

## Technical validation
Verify image dimensions, format, file size, loading behavior, and fallback assets. Ensure asset identifiers remain stable so saved progress does not point to a different question after a content update.

## Release checks
Run the question pack through answer acceptance tests, random-order sampling, offline/loading checks, and a small-screen layout review. Remove broken or unverified assets before release.

## Sign-off record
Record pack version, reviewer, review date, unresolved issues, and release decision.
