# Release Smoke Test — 2026-09-06

Run this short pass after building the app or changing question data.

- [ ] App launches without a crash.
- [ ] Main screen renders the current question and image.
- [ ] Correct and incorrect answers produce distinct feedback.
- [ ] Next-question flow advances exactly once.
- [ ] Restarting the app returns to a valid initial state.
- [ ] No answer or asset path is blank in the release build.

Record the device/emulator version and build identifier with any failure so it can be reproduced.
