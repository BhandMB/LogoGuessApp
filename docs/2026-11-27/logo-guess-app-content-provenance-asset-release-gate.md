# Content provenance and asset release gate

## Asset register
For each logo/image, record source, creator or rights holder, license/permission basis, permitted uses, attribution text, retrieval date, and modifications. Keep evidence with the asset or in a maintained register.

## Release checks
- Confirm each asset is original, licensed, public domain, or supported by documented permission.
- Verify attribution in shipped UI and repository notices.
- Replace assets with unclear provenance; online availability does not imply reuse rights.
- Check that generated/edited assets do not misleadingly reproduce protected marks.
- Ensure shipped assets are not watermarked or low-resolution previews.

## Review outcome
Mark each asset approved, needs attribution, replace, or blocked. Release only when every shipped asset has a documented disposition.
